# Pharmacy_-Management-System


A professional Pharmacy Management and Billing Application designed to help pharmacies efficiently manage medicines, inventory, suppliers, categories, sales, and invoices from a single platform.

💊 Medicine Management

The application allows users to maintain complete medicine records, including:

Medicine Name
Brand / Type
Category
Batch Number
Preparation
Expiry Date
Purchase Price
Selling Price
Stock Quantity

Users can also add, edit, and delete medicine records whenever required.

🧾 Invoice Management

The application provides a complete medicine billing system that allows users to:

Create medicine invoices
Add medicines to invoices
Edit invoices
Delete invoices
Save invoices
Share invoices

This makes the billing process faster and more organized.

📂 Category Management

Users can manage medicine categories according to their business requirements.

Add categories
Edit categories
Delete categories
Organize medicines by category
🚚 Supplier Management

The application also provides supplier management functionality for maintaining supplier information and managing medicine supplies.

Users can add, update, and manage supplier records to keep purchasing information organized.

📦 Stock Management

The application helps users monitor and manage medicine inventory efficiently.

Track available stock
Manage medicine quantities
Update stock records
Monitor inventory
Maintain accurate stock information
📊 Sales Management

Users can view medicine sales for a specific date, making it easier to track daily business transactions and review sales records.

🎯 Project Objective

The main objective of this application is to provide pharmacies and medicine businesses with a centralized solution for managing medicines, stock, suppliers, invoices, and sales. It helps reduce manual record keeping and makes everyday pharmacy management more efficient and organized.
